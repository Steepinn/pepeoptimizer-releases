# PepeOptimazer

[Download the Windows installer](https://github.com/Steepinn/pepeoptimizer-releases/releases/latest)

Download `PepeOptimazerSetup.exe` from the release assets and install it on Windows 10/11 (64-bit).

The app checks for new versions at startup and in the background. Downloads are verified with SHA-256. Updates install automatically when no optimization task or game recording is active; settings, backups and existing licenses are preserved.

## Pepe+

A license is bound to one PC. First activation uses GitHub sign-in. Your activation request is public under your GitHub username, but the license key and device identifier are encrypted before publication. GitHub Actions processes the request using repository Secrets. Private credentials are never distributed in the installer.

Existing licenses are verified with signed public status records. Downloads, updates and subsequent license checks do not require GitHub sign-in.
